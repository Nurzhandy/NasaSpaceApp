# План v2: SPACE EXPLORERS

Реализация «Объединённого технического задания (Master Prompt v2.0)» на **нашем текущем стеке**.
Ресёрч реальных заданий на корабле и на Луне — в приложениях в конце файла.

**Часть A — друг. Часть B — я.**

## 0. Что берём из ТЗ, а что заменяем

**Стек не меняем:** Rust + Bevy 0.16, десктоп-приложение (Windows / macOS / Linux). Правила игры — в `crates/core` (`ja-core`, без Bevy), всё, что видно и слышно, — в `crates/game`. Сеть — наш UDP из `net.rs`, где хост считает правила.

| В ТЗ | У нас вместо этого |
|---|---|
| Браузерная игра | Десктоп-приложение. Позже Bevy можно собрать в WebAssembly, но наша UDP-сеть в браузере работать не будет |
| PostgreSQL, сервер | JSON-файлы на компьютере: **личное** сохранение (`~/.junior_astronaut_outpost.json`, уже есть) и **экспедиция** (`~/.junior_astronaut_mission.json`, уже есть). В сетевой игре экспедицию сохраняет хост |
| Серверная проверка монет и результатов | Хост — единственный, кто считает правила и начисляет монеты. Гость шлёт только команды, хост их проверяет. Так уже устроено в `net.rs` |
| Регистрация, пароли, восстановление | **Локальные профили**: никнейм, аватар, без пароля и почты. «Удалить аккаунт» = удалить профиль |
| Admin Panel (веб) | **Папка контента** `assets/content/*.json` + проверка `cargo test -p ja-core content` + перезагрузка контента прямо в игре (F5 в режиме разработчика). Методист правит JSON, код не трогает |
| Покупки за реальные деньги, родительский контроль | **Реальных денег в игре нет вообще.** Это проще и безопаснее для детей. Монеты зарабатываются только игрой |
| Чат, фильтр текста | **Только готовые быстрые фразы и смайлы**, без свободного текста. Комнаты закрыты кодом, есть «заглушить игрока» |
| Интернет-игра | Пока только локальная сеть (одна Wi‑Fi). Для игры через интернет нужен сервер — это отдельный этап |

## 2. Противоречия в ТЗ и решения

Это мои рекомендации. Если не согласен — правим здесь до начала работы.

1. **Game Over против «экипаж не гибнет».** ТЗ прямо требует Game Over, если прочность и герметичность упали до нуля. Делаем, но мягко для детей: «Корабль не выдержал. Экипаж эвакуирован», и кнопка «Начать день заново» (с контрольной точки, а не с самого начала).
2. **Астероиды между Землёй и Луной.** В реальности их там почти нет. Мини-игра — **игровая условность**, и это честно пишем. Карточка Advanced: «Настоящая угроза — микрометеороиды размером с песчинку».
3. **«Буря лунной пыли».** На Луне нет ветра, поэтому бурь, как на Марсе, не бывает. Честная замена: облако пыли от посадки грузового корабля или работы ровера, плюс заряженная пыль на границе дня и ночи. В игре событие можно назвать «пылевое облако» с подписью «игровое упрощение».
4. **«Запас электричества» и «генерация энергии».** Для Advanced разделяем: **энергия** (запас в батарее, кВт·ч) и **мощность** (генерация и потребление, кВт). Это требование самого ТЗ — не смешивать величины.
5. **Карточки понятий.** У каждой карточки есть тип: *величина* (скорость v, ускорение a, сила F, масса m, импульс p, кинетическая энергия Eк), *явление* (инерция, гравитация) или *понятие* (траектория — это линия, а не величина). Формулы показываем обычным текстом с Unicode: `F = G·m₁·m₂ / r²` (Bevy не рисует LaTeX).
6. **Солнечная система.** Делать все 9 планет играбельными — слишком много. Сейчас: карта планет и энциклопедия со всеми планетами из JSON, **играбельна только Луна**. Старые карты Марс, Европа и Орбита — кандидаты в следующие экспедиции.
7. **Контент пишет команда, а не ИИ.** Мы делаем загрузку и показ. В JSON кладём только стартовые примеры из ТЗ и из приложений 1–2, помеченные `"draft": true`. Методисты заменяют их своими текстами.
8. **Казахский язык.** Если перевода нет, показываем русский текст и пишем ключ в отчёт проверки контента. Сам перевод делает команда (носитель языка).
9. **Название.** Игра теперь называется «SPACE EXPLORERS». Меняем заголовок окна, меню и README.

## 4. Контракт (шаг 0) — делает A, проверяет B

Один маленький PR. Пока он не влит, B начинает с посадки и тепла: они ни от чего не зависят.

### `ja-core`

```rust
// expedition.rs — настройки до старта (экран «Создание экспедиции»)
pub enum PlayMode { Survival, Creative }      // меняется только до старта
pub enum Level { Junior, Advanced }           // заменяет cadet: bool
pub struct ExpeditionConfig { pub mode: PlayMode, pub level: Level, pub players: u8 /* 1..=4 */, pub roles: [Option<Role>; 4], pub seed: u64 }
pub enum Role { Pilot, Engineer, Researcher, LifeSupport }   // бонус, но ничего не запрещает

// campaign.rs — одна непрерывная история
pub enum Phase { Ship { day: u8 }, Landing, Moon { day: u8 }, GameOver(Cause), Done }
pub struct Campaign { /* фаза, ship: Ship, moon: Option<Game>, wallet: Wallet, ... */ }
impl Campaign {
    pub fn new(cfg: ExpeditionConfig, content: &Content, weather: &Weather) -> Self;
    pub fn tick(&mut self, dt: f32) -> Vec<CampaignEvent>;
    pub fn apply(&mut self, player: u8, cmd: CampaignCommand) -> Result<Vec<CampaignEvent>, Refusal>;
    pub fn state(&self) -> &CampaignState;
    pub fn checkpoint(&self) -> Checkpoint;      // начало дня — для «Начать день заново» и сохранения
}

// wallet: общий бюджет экспедиции (стройка, ремонт) + личные монеты игрока (косметика)
pub struct Wallet { pub team: u32, pub personal: [u32; 4] }

// content.rs — весь текст и данные из assets/content/*.json
pub struct Text { pub ru: String, pub kk: Option<String>, pub en: String }   // kk нет → показываем ru
pub struct LevelText { pub junior: Text, pub advanced: Option<Text> }
pub struct Content { pub ui, pub npcs, pub dialogs, pub missions, pub physics_cards, pub planets, pub events, pub shop }
pub fn load(dir: &Path) -> Result<Content, Vec<ContentError>>;    // ошибки — с файлом и ключом
```

- `Lang` получает `Kk`. `i18n::pick(ru, en)` остаётся для старого кода, новые тексты идут через `Content`.
- `Game` (Луна) принимает до 4 игроков. Сейчас там `coop: bool` и индексы 0/1.

### Формат контента (пример)

```json
// assets/content/physics_cards.json
[{ "id": "inertia", "kind": "phenomenon", "symbol": null, "formula": null,
   "junior":   { "ru": "Корабль продолжает лететь, даже когда двигатель выключен…", "kk": null, "en": "…" },
   "advanced": { "ru": "Инерция — явление сохранения скорости тела…", "kk": null, "en": "…" },
   "after": "asteroid_episode_1", "draft": true }]
```

Файлы: `ui.json`, `npcs.json`, `dialogs/*.json` (ветки, условия появления, привязка к квестам), `missions/*.json`, `physics_cards.json`, `planets/*.json` (атмосфера, температура, гравитация, поверхность, история, открытия, Junior / Advanced), `events.json`, `shop.json`, `ship_rooms.json`.

## Приложение 1. Задания на корабле (часть A)

Корабль — свой, вымышленный: **«Аврора»**. Он больше настоящего «Ориона», чтобы внутри было где ходить. Это честно пишем на странице источников.

**Отсеки (вид сверху, игрок ходит между пультами):** кабина (пилотирование, навигация, связь) · жилой отсек (еда, сон, видеозвонок) · спортзал · лаборатория · жизнеобеспечение (воздух, CO₂, вода) · туалет · склад и шлюз (скафандры, сумки) · двигательный отсек.

### П1.1. Задания по распорядку (каждый день, спокойные)

| Задание | Что в реальности | Мини-игра (10–40 с) |
|---|---|---|
| Предстартовый опрос «Go / No-Go» | Перед стартом каждый пост ЦУП отвечает «готов» | Пройти по списку: нажать «Go», когда лампочка поста зелёная |
| Проверка систем после старта | На «Артемиде II» экипаж сутки проверял системы «Ориона» | Включить системы по порядку, пока все лампы не станут зелёными |
| Ручное управление | «Артемида II» вручную подлетала к отработанной ступени | Подвести корабль к цели, не превышая скорость |
| Разгон к Луне (TLI) | Главный манёвр полёта | Держать двигатель, отпустить, когда стрелка в зелёной зоне |
| Коррекция курса | Аполлоны делали 1–4 маленьких коррекции по пути | Совместить стрелку курса с Луной, короткий импульс |
| Навигация по звёздам | Майкл Коллинз (Аполлон‑11) мерил звёзды секстантом на случай потери связи | Найти нужную звезду и навести на неё перекрестие |
| «Барбекю-вращение» | Корабль медленно вращают, чтобы Солнце грело равномерно | Держать полоску «жарко/холодно» в середине |
| Зарядка | На МКС ~2 часа спорта в день против потери мышц и костей | Ритм-игра на тренажёре |
| Еда | Еду разводят водой из бортового крана | Выбрать блюдо, налить нужное количество воды |
| Вода | На МКС перерабатывают ~98% воды | Заменить фильтр, проверить, что вода чистая |
| Связь с Землёй | Сеть дальней связи NASA: Голдстоун, Мадрид, Канберра | Выбрать антенну, которая сейчас «видит» корабль (Земля вращается) |
| Научный эксперимент | На «Артемиде II» были опыты с клетками экипажа (AVATAR) | Положить образцы в нужные ячейки по цвету |
| Проверка скафандра | На «Артемиде II» в 5-й день тестировали скафандры | Надеть скафандр по шагам, найти утечку по пузырькам |
| Фото Земли / Луны в иллюминатор | Экипажи фотографируют Землю и Луну | Поймать кадр в рамку (награда, передышка) |
| Видеозвонок семье, сон | Психологическая поддержка, режим сна | Передышка; связь с психо-частью (назови чувство) |

### П1.2. Проблемы (срочные, с таймером)

| Проблема | Реальный случай | Мини-игра / решение |
|---|---|---|
| **Молния при старте**, приборы показывают ерунду | Аполлон‑12, 1969: «Переключи SCE на AUX» | За 10 секунд найти и переключить рычаг запасного питания |
| **Туалет сломался** | «Артемида II», 2026: заклинило вентилятор, потом замёрзла трубка слива | Шаг 1: починить вентилятор. Шаг 2: повернуть корабль, чтобы Солнце растопило лёд |
| **CO₂ растёт** | Аполлон‑13, 1970: квадратные фильтры не влезали в круглые гнёзда | Собрать переходник «квадрат в круг» из шланга, картона и скотча |
| **Солнечная вспышка** (данные DONKI, LIVE/АРХИВ) | «Артемида II» проверяла укрытие, построенное из сумок | Быстро перенести сумки и построить укрытие, спрятать экипаж |
| **Утечка воздуха** от микрометеорита | Угроза для всех кораблей | Найти шипение по звуку и заклеить пробоину |
| **Перегрев одной стороны** | Если остановить «барбекю-вращение» | Снова запустить вращение |
| **Космическая болезнь** в первый день | У многих астронавтов в первые сутки | Дыхание-маяк, вода, отдых (связь с психо-частью) |
| **Нет связи за Луной** (по сценарию, не авария) | «Артемида II» ~40 минут без связи за обратной стороной Луны | Выход на орбиту Луны по чек-листу без подсказок ЦУП |

### П1.3. Дни полёта (сценарий)

| День | Что происходит | Проблемы |
|---|---|---|
| 1. Старт | Опрос Go/No-Go → старт (сцена в иллюминаторе) → отделение ступеней → орбита: проверка систем, ручное управление → разгон к Луне | Молния при старте, космическая болезнь |
| 2. Путь | Зарядка, еда, вода, навигация по звёздам, коррекция курса, связь | Туалет, солнечная вспышка |
| 3. Далеко от дома | Скафандр, эксперимент, фото Земли, звонок семье | CO₂ (Аполлон‑13), утечка воздуха, перегрев |
| 4. Луна | Выход на орбиту Луны за обратной стороной → переход в посадочный модуль | Без связи с ЦУП → **передаём части B** |

Длина: один день ≈ 4–6 минут игры, весь полёт ≈ 20 минут.

## Приложение 3. «Режиссёр» — чтобы не было скучно

Одна логика и для корабля, и для Луны (`ja-core`, без Bevy). Правила:

1. **У игрока всегда есть цель.** Если 30 секунд нет активного задания, режиссёр выдаёт маленькое дело (обычное задание или находку).
2. **Волна: спокойно → проблема → передышка.** После срочной проблемы — награда и спокойный момент: фото Земли, звонок семье, реплика экипажа.
3. **Напряжение растёт по дням.** День 1 — одна проблема, день 3 — до двух сразу.
4. **Junior:** не больше одной срочной проблемы одновременно, таймеры в 1,5 раза длиннее.
5. **Сюжет главнее случайности.** Сюжетные события (старт, разгон, выход на орбиту Луны, посадка) идут по расписанию. Случайные проблемы берутся из пула с перезарядкой, чтобы одна и та же не повторялась подряд.
6. **Провал — не конец.** Не успел решить проблему — есть последствия (меньше воздуха, воды или очков, ЦУП помогает советом), но игра идёт дальше. Исключение — Game Over корабля (раздел 2, пункт 1).
7. **Честность данных.** Исторические события подписаны «история: Аполлон‑13, 1970». Вспышки — DONKI с подписью LIVE или АРХИВ.

**Тест режиссёра:** бот проходит кампанию 300 раз. Проверяем, что: нет пауз длиннее 30 секунд без цели; срочных проблем одновременно не больше лимита; аккуратный игрок долетает и садится всегда; небрежный тоже долетает, но с меньшим счётом.
