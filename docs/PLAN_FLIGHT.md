## 1. Что меняем и зачем

**Было:** главное меню → выбор карты (Земля, Луна, Марс, Орбита, Европа) → брифинг → миссия на базе. Карты открываются за очки.

**Будет:** главное меню → **«Начать»** → одна сплошная история:

```
Старт с Земли ─► Орбита Земли ─► 2 дня полёта к Луне ─► Орбита Луны ─► Посадка ─► Жизнь на Луне
 (день 1)          (день 1)        (дни 2–3, корабль)      (день 4)       (день 4)    (солы 1–5)
└────────────────────── ЧАСТЬ 1 (друг) ──────────────────────┘└──────── ЧАСТЬ 2 (я) ────────┘
```

**Главное правило: всё время что-то происходит.** В каждый момент у игрока есть цель: обычное дело по распорядку, срочная проблема или награда. На корабле — короткие задания у пультов, как в играх «найди пульт и выполни мини-игру». На Луне — стройка базы, вылазки и проблемы, которые нужно решать.

**Почему так (выводы ресёрча):**
- Реальные полёты состоят из **распорядка + неожиданных проблем**. У МКС расписание расписано по 5 минут, а на «Артемиде II» в апреле 2026 года главной проблемой полёта стал… туалет. Это смешно, понятно ребёнку и при этом правда.
- Самые запоминающиеся истории космоса — это **проблемы, которые решили смекалкой**: «квадратный фильтр в круглое гнездо» (Аполлон‑13), «переключи на запасное питание» (Аполлон‑12, молния), «компьютер перегружен, продолжаем» (Аполлон‑11), «крыло ровера из карт и скотча» (Аполлон‑17). Каждая из них — готовая мини-игра.
- Игры держат внимание чередованием **напряжения и передышки** (AI Director в Left 4 Dead, «рассказчики» в RimWorld). Поэтому нужен «режиссёр»: он раздаёт задания, следит, чтобы не было скучно, и не валит на ребёнка три аварии сразу.
- Мини-игры в стиле «подойди к пульту и сделай короткое действие» (провода, кнопки по порядку, совмести стрелки, держи кнопку) знакомы детям 7–12. **Берём только тип механики**: названия, арт и задания у нас свои, основанные на настоящих полётах.

**Что остаётся:** пиксель-арт, ходьба, стройка базы, вспышки NASA DONKI с подписью LIVE/АРХИВ, психологическая подготовка (дыхание-маяк, назови чувство, поддержи экипаж), скины и нашивки, RU/EN, возраст «Кадет 7–9», без гибели экипажа. Старые карты (Марс, Европа и т. д.) **не удаляем из кода**, только убираем из меню. Тесты и баланс должны работать.

## 2. Ресёрч: задания на корабле (часть 1)

Корабль — свой, вымышленный: **«Аврора»**. Он больше настоящего «Ориона», чтобы внутри было где ходить. Это честно пишем на странице источников.

**Отсеки (вид сверху, игрок ходит между пультами):** кабина (пилотирование, навигация, связь) · жилой отсек (еда, сон, видеозвонок) · спортзал · лаборатория · жизнеобеспечение (воздух, CO₂, вода) · туалет · склад и шлюз (скафандры, сумки) · двигательный отсек.

### 2.1. Задания по распорядку (каждый день, спокойные)

| Задание | Что в реальности | Мини-игра (10–40 с) |
|---|---|---|
| Предстартовый опрос «Go / No-Go» | Перед стартом каждый пост ЦУП отвечает «готов» | Пройти по списку: нажать «Go», когда лампочка поста зелёная |
| Проверка систем после старта | На «Артемиде II» экипаж сутки проверял системы «Ориона» | Включить системы по порядку, пока все лампы не станут зелёными |
| Ручное управление | «Артемида II» вручную подлетала к отработанной ступени | Подвести корабль к цели, не превышая скорость |
| Разгон к Луне (TLI) | Главный манёвр полёта | Держать двигатель, отпустить, когда стрелка в зелёной зоне |
| Коррекция курса | Аполлоны делали 1–4 маленьких коррекции по пути | Совместить стрелку курса с Луной, короткий импульс |
| Навигация по звёздам | Майкл Коллинз (Аполлон‑11) мерил звёзды секстантом на случай потери связи | Найти нужную звезду и навести на неё перекрестие |
| «Барбекю-вращение» | Корабль медленно вращают, чтобы Солнце грело равномерно | Держать полоску «жарко/холодно» в середине |
| Зарядка | На МКС ~2 часа спорта в день против потери мышц и костей | Ритм-игра на тренажёре |
| Еда | Еду разводят водой из бортового крана | Выбрать блюдо, налить нужное количество воды |
| Вода | На МКС перерабатывают ~98% воды | Заменить фильтр, проверить, что вода чистая |
| Связь с Землёй | Сеть дальней связи NASA: Голдстоун, Мадрид, Канберра | Выбрать антенну, которая сейчас «видит» корабль (Земля вращается) |
| Научный эксперимент | На «Артемиде II» были опыты с клетками экипажа (AVATAR) | Положить образцы в нужные ячейки по цвету |
| Проверка скафандра | На «Артемиде II» в 5-й день тестировали скафандры | Надеть скафандр по шагам, найти утечку по пузырькам |
| Фото Земли / Луны в иллюминатор | Экипажи фотографируют Землю и Луну | Поймать кадр в рамку (награда, передышка) |
| Видеозвонок семье, сон | Психологическая поддержка, режим сна | Передышка; связь с психо-частью (назови чувство) |

### 2.2. Проблемы (срочные, с таймером)

| Проблема | Реальный случай | Мини-игра / решение |
|---|---|---|
| **Молния при старте**, приборы показывают ерунду | Аполлон‑12, 1969: «Переключи SCE на AUX» | За 10 секунд найти и переключить рычаг запасного питания |
| **Туалет сломался** | «Артемида II», 2026: заклинило вентилятор, потом замёрзла трубка слива | Шаг 1: починить вентилятор. Шаг 2: повернуть корабль, чтобы Солнце растопило лёд |
| **CO₂ растёт** | Аполлон‑13, 1970: квадратные фильтры не влезали в круглые гнёзда | Собрать переходник «квадрат в круг» из шланга, картона и скотча |
| **Солнечная вспышка** (данные DONKI, LIVE/АРХИВ) | «Артемида II» проверяла укрытие, построенное из сумок | Быстро перенести сумки и построить укрытие, спрятать экипаж |
| **Утечка воздуха** от микрометеорита | Угроза для всех кораблей | Найти шипение по звуку и заклеить пробоину |
| **Перегрев одной стороны** | Если остановить «барбекю-вращение» | Снова запустить вращение |
| **Космическая болезнь** в первый день | У многих астронавтов в первые сутки | Дыхание-маяк, вода, отдых (связь с психо-частью) |
| **Нет связи за Луной** (по сценарию, не авария) | «Артемида II» ~40 минут без связи за обратной стороной Луны | Выход на орбиту Луны по чек-листу без подсказок ЦУП |

### 2.3. Дни полёта (сценарий)

| День | Что происходит | Проблемы |
|---|---|---|
| 1. Старт | Опрос Go/No-Go → старт (сцена в иллюминаторе) → отделение ступеней → орбита: проверка систем, ручное управление → разгон к Луне | Молния при старте, космическая болезнь |
| 2. Путь | Зарядка, еда, вода, навигация по звёздам, коррекция курса, связь | Туалет, солнечная вспышка |
| 3. Далеко от дома | Скафандр, эксперимент, фото Земли, звонок семье | CO₂ (Аполлон‑13), утечка воздуха, перегрев |
| 4. Луна | Выход на орбиту Луны за обратной стороной → переход в посадочный модуль | Без связи с ЦУП → **передаём часть 2** |

Длина: один день ≈ 4–6 минут игры, весь полёт ≈ 20 минут.

## 3. Ресёрч: посадка и задания на Луне (часть 2)

### 3.1. Посадка

| Шаг | Реальность | Игра |
|---|---|---|
| Выбор площадки у южного полюса | Будущие посадки — у южного полюса: там свет на гребнях кратеров и лёд в тёмных кратерах | Выбор: «светло, но далеко ото льда» / «рядом лёд, но камни» / «ровно, но мало солнца» — у каждой площадки своя цена |

| Неудача | — | Никто не погибает: «Прерываем посадку!», возврат на орбиту, повторная попытка (минус очки и топливо) |

### 3.2. Задания на Луне (по солам)

Используем существующий аванпост (`ja-core`: стройка, энергия, находки, области Малаперт и Шеклтон, финал), но с новым сюжетом и «режиссёром».

| Сол | Задания |
|---|---|
| 1. Первые шаги | Спуститься по лестнице, флаг и фото, доклад ЦУП, разгрузить груз, поставить купол и солнечные панели |
| 2. Лаборатория под открытым небом | Собрать ровер, поставить приборы: сейсмометр (как будущая станция LEMS у полюса), лазерный отражатель, метеостанцию. Образцы: грабли, трубка-керн, бур |
| 3. Лёд в темноте | Экспедиция в постоянно тёмный кратер за льдом: холод, фонарь, заряд скафандра. Анализ в лаборатории |
| 4. Строим аванпост | Оранжерея, генератор O₂ из льда, ретранслятор связи |
| 5. Финал | Существующий финал (вспышка Кэррингтона 1859 года, подписана как история) |

### 3.3. Проблемы на Луне

| Проблема | Реальность | Решение |
|---|---|---|
| **Лунотрясение** | Сейсмометры Аполлонов записали больше 12 000 лунотрясений, мелкие — до магнитуды 5 | Найти трещины в модулях и заделать |
| **Сломалось крыло ровера** | Аполлон‑17: крыло сделали из 4 карт и скотча | Собрать крыло из карт и скотча, иначе пыль летит на скафандр |
| **Пыль** | Лунная пыль липнет и царапает всё | Чистить панели, скафандр и шлюз |
| **Микрометеорит** | Нет атмосферы — нет защиты | Заделать пробоину в модуле |
| **Солнечная вспышка** (DONKI LIVE/АРХИВ) | Уже есть в игре | В убежище, щит |
| **Связь пропадает** | У полюса Земля низко над горизонтом | Поставить ретранслятор на гребне |
| **Кончается заряд скафандра** | Каждая вылазка ограничена по времени | Вернуться на базу вовремя |
| **Долгая тень / холод** | Ночью до −130 °C, днём до +120 °C | Энергия, батареи, обогрев |
| **Поломка генератора** | Уже есть в игре | Держать F рядом |

## 4. «Режиссёр» — чтобы не было скучно

Одна логика и для корабля, и для Луны (`ja-core`, без Bevy). Правила:

1. **У игрока всегда есть цель.** Если 30 секунд нет активного задания, режиссёр выдаёт маленькое дело (обычное задание или находку).
2. **Волна: спокойно → проблема → передышка.** После срочной проблемы — награда и спокойный момент: фото Земли, звонок семье, реплика экипажа.
3. **Напряжение растёт по дням.** День 1 — одна проблема, день 3 — до двух сразу.
4. **«Кадет 7–9»:** не больше одной срочной проблемы одновременно, таймеры в 1,5 раза длиннее.
5. **Сюжет главнее случайности.** Сюжетные события (старт, разгон, выход на орбиту Луны, посадка) идут по расписанию. Случайные проблемы берутся из пула с перезарядкой, чтобы одна и та же не повторялась подряд.
6. **Провал — не конец.** Не успел решить проблему — есть последствия (меньше воздуха, воды или очков, ЦУП помогает советом), но игра идёт дальше.
7. **Честность данных.** Исторические события подписаны «история: Аполлон‑13, 1970». Вспышки — DONKI с подписью LIVE или АРХИВ.

**Тест режиссёра:** бот проходит кампанию 300 раз. Проверяем, что: нет пауз длиннее 30 секунд без цели; срочных проблем одновременно не больше лимита; аккуратный игрок долетает и садится всегда; небрежный тоже долетает, но с меньшим счётом.

### Ядро (`crates/core`)

Новый файл `campaign.rs`:

```rust

pub enum TaskKind {            // все задания и проблемы: и корабль, и Луна
    // корабль (часть 1): GoNoGo, SystemsCheck, ManualDock, Tli, CourseFix, StarSight, Rotate,
    //   Exercise, Meal, Water, Comms, Experiment, SuitCheck, Photo, CallHome,

    // Луна (часть 2): LandingSite, Descent, Flag, DeployExperiment, Rake, Core, IceTrip,
    //   Quake, Fender, Dust, Relay, SuitBattery, ...
}

pub struct Task { pub id: u32, pub kind: TaskKind, pub station: Station, pub urgent: Option<f32>, pub step: u8 }
pub enum Outcome { Done { score: u8 }, Failed, Skipped }

pub struct Campaign { /* фаза, день, задания, ресурсы корабля, режиссёр, вложенный Game на Луне */ }
impl Campaign {
    pub fn new(cfg: CampaignConfig, weather: &Weather) -> Campaign;
    pub fn tick(&mut self, dt: f32) -> Vec<CampaignEvent>;
    pub fn finish(&mut self, task: u32, out: Outcome) -> Vec<CampaignEvent>;
    pub fn state(&self) -> &CampaignState;
    pub fn surface(&mut self) -> Option<&mut Game>;   // на Луне — обычный Game, как сейчас
    pub fn save(&self) -> CheckpointSave;             // контрольная точка: начало дня / сола
}

pub enum CampaignEvent { PhaseChanged(Phase), TaskAdded(u32), TaskExpired(u32), Emergency(TaskKind), Calm, Radio(Msg), Ended(CampaignResult) }
```

`director.rs` — каркас режиссёра (правила раздела 4) с одним тестом. Каждая часть потом сама наполняет свой пул заданий.

### Игра (`crates/game`)

- `AppState::Campaign`: «Начать» в меню сразу запускает кампанию. Карты и брифинг уходят из меню.
- `minigame.rs`: окно мини-игры — открыть по `TaskKind`, таймер, закрыть, вернуть `Outcome` в ядро. Каждая мини-игра — отдельный плагин, который реализует один трейт или функцию `spawn_ui / update / result`.
- `tasks_hud.rs`: список заданий слева (иконка, отсек, таймер у срочных), стрелка к нужному пульту.

## 9. Правила Git

- Ветки `part-1/<задача>` и `part-2/<задача>`, в `main` — только через PR.
- **Друг трогает:** `core/src/voyage.rs`, `i18n_ship.rs`, `game/src/ship/`.
- **Я трогаю:** `core/src/landing.rs`, `game.rs`, `data.rs`, `i18n.rs`, `game/src/landing.rs`, `game/src/moon/`, `menu.rs`, `save.rs`.
- **Общие файлы** (`campaign.rs`, `director.rs`, `lib.rs`, `main.rs`, `minigame.rs`, `tasks_hud.rs`) меняем маленьким PR и предупреждаем друг друга.
- Перед PR: `cargo fmt`, `cargo clippy`, `cargo test`.
