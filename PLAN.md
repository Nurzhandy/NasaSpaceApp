# План: «Юный астронавт: Аванпост» — 3D-игра на Rust (Bevy)

Хакатон NASA Space Apps 2026, челлендж **Junior Astronaut Mission Trainer** (дети 7–12).
Критерии судей: Impact · Creativity · Validity · Relevance · Presentation.

## Концепция (утверждено)
- **Полноценная 3D-игра** от третьего лица: астронавт ходит/прыгает по базе на Луне/Марсе.
- Стек: **Rust + Bevy 0.16** (нативное приложение macOS/Windows/Linux; WASM — бонус, если успеем).
- Дизайн: минимум текста, крупные иконки (OpenMoji), крупные кнопки, 2 языка (RU/EN).
- Ядро геймплея: делить энергию базы между **кислородом, едой, щитом и наукой**; ни одно решение не бесплатно.
- События — **реальные вспышки NASA DONKI** (live через api.nasa.gov, иначе честный «АРХИВ»).
- Психологическая подготовка (из ресерч-дока): план «если — то», пауза перед действием, маяк-дыхание, поддержка экипажа, разбор после миссии. Экипаж не погибает — эвакуация.
- Прогресс: 🏅 очки открывают карты (Земля → Луна 60 → Марс 180 → Орбита 400 → Европа 700); ⭐ звёзды тратятся на скины (скафандр, визор, украшение на шлем). Покупка не закрывает карты.
- Одиночная игра и **кооператив на разделённом экране** (2 игрока: клавиатура WASD+F / стрелки+RShift, или 2 геймпада) — разделены в меню.

## Как продолжить, если сессия оборвалась
```bash
cd ~/Desktop/NasaSpaceApp
cargo run            # dev-сборка; release: cargo run --release
```
Windows: нужны Visual Studio Build Tools с «Разработка классических приложений на C++».
Скриншот-тур: `JA_SHOTS=docs/screenshots JA_PROFILE=docs/screenshots/profile.json cargo run --release`.
Ключ NASA: `NASA_API_KEY=... cargo run` (без ключа — DEMO_KEY, лимит ~30 запросов/час).

## Управление
| Действие | Игрок 1 | Игрок 2 (кооп) | Геймпад |
|---|---|---|---|
| Ходить | WASD | стрелки | левый стик |
| Прыжок | Space | Right Ctrl | X / Y |
| Действие / держать | F или Enter | Right Shift | A |
| Камера | мышь (зажать) / Q E | , . | правый стик |
| Пауза / закрыть окно | Esc | — | Start / B |
